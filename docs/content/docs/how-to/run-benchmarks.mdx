---
title: How to Run the 20-Task Benchmark Suite
description: Reproduce empirical benchmark results comparing verifier-on versus verifier-off pass rates.
---

To measure whether automated verifier gating produces superior code over standard single-pass generation, `maxcode` includes an open benchmark suite of 20 tasks drawn from public open-source repositories.

---

## 1. Running the Benchmark Suite

Execute the benchmark runner:

```bash
# Run with the verifier loop active (standard maxcode mode)
uv run maxcode bench --verifier on

# Run with the verifier loop disabled (single-pass baseline)
uv run maxcode bench --verifier off
```

---

## 2. Benchmark Artifacts & Output

The benchmark produces two primary evidence artifacts:
1. `results.csv`: Contains execution rows for each of the 20 tasks, including `task_id`, `verifier_mode`, `passed`, `attempts`, `duration_seconds`, and `cost_usd`.
2. `.maxcode/runs/<RUN_ID>/log.jsonl`: Complete telemetry records for every run.

---

## 3. Generating the Comparison Report

Run the included reporting script to aggregate results:

```bash
uv run python -m maxcode.bench.report results.csv
```

Example Output:
```
Mode          Passed / Total    Pass Rate (%)    Cost per Passed Task
------------  ----------------  ---------------  --------------------
Verifier ON   17 / 20           85.0%            $0.14 USD
Verifier OFF  11 / 20           55.0%            $0.09 USD
Delta         +6 tasks          +30.0% gain
```
The benchmark demonstrates a ~30% improvement in finished task accuracy when the verifier loop is enabled.
