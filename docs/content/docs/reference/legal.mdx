## 1. Open-Source License

`maxcode` is licensed under the **Apache License, Version 2.0** (`Apache-2.0`).

- **Fork Source:** The core engine adapter builds on the open-source OpenAI Codex CLI under Apache-2.0.
- **Attribution:** The original `LICENSE` and `NOTICE` files from the Codex repository are preserved in full in the repository root.
- **SPDX Headers:** Every source file carries an SPDX identifier:
  `# SPDX-License-Identifier: Apache-2.0`

---

## 2. Independence from Proprietary Services

- **No Affiliation:** `maxcode` is an independent open-source project. It is not affiliated with, sponsored by, or endorsed by OpenAI or Sarvam AI.
- **No Proprietary Code:** The proprietary Codex security plugin is excluded. No proprietary binaries or decompiled assets were used.
- **Open Alternative:** `maxcode` is positioned as an open, verifiable alternative for developers seeking transparent local execution.

## 3. Legal Compliance Checklist (PRD Section 8)

- `L1`: LICENSE and NOTICE files present and intact.
- `L2`: Every source file carries an SPDX license header.
- `L3`: Codex name and logo removed from all user-facing output.
- `L4`: Zero proprietary names, logos, fonts, or assets used.
- `L5`: No reverse engineering of proprietary binaries.
- `L6`: All documentation, site copy, and assets written from zero.
- `L7`: Zero affiliation claimed with third parties.
- `L8`: Product described strictly as an open alternative.
- `L9`: Trademark availability verified across open software registries.
- `L10`: All third-party library licenses audited and listed in NOTICE.
